# Katmai National Park – 3D Scene

A 3D computer graphics project developed in **C (OpenGL)**, inspired by Katmai National Park in Alaska and the story of Timothy Treadwell.

### Features

- 3D environment with bears, foxes, fish and mountains
- Textures and OBJ/MTL models
- Snow particle system
- Animated river and animals
- Day/night cycle
- Multiple lighting modes
- GLSL shaders
- Interactive camera and controls

### Technologies and software

C, OpenGL, FreeGLUT, GLEW, GLSL, STB Image, 
Code::Blocks , Blender , Mixamo , Sketchfab , 3D Viewer
